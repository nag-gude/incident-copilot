Each file includes:

- **How we use the sponsor tech** – High-level alignment with the challenge
- **What we built** – Integration point, trigger, flow, user-visible outcome
- **Technical details** – APIs, config, code locations
- **How to verify** – Steps for demo/judging
- **Links** – To code and main docs

Use these as the basis for “Sponsor X” sections in your submission or for copy-paste into Devpost fields.
